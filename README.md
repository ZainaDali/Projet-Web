# Messenger Web - Projet Scolaire

Bienvenue sur le projet Messenger Web, une application de messagerie instantanée.

## Description

Ce projet est composé de deux parties :
- **Backend** : API NestJS avec Prisma, gestion des utilisateurs, conversations, messages et file d’attente BullMQ/Redis.
- **Frontend** : Application web React (Vite) pour l’interface utilisateur.

---

## Structure des branches

- **Backend** :  
  Le code du backend se trouve sur la branche **`deploy-imane`**.

- **Frontend** :  
  Le code du frontend se trouve sur la branche **`queue-websocket`**.
